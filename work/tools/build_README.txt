ROV-Sim 1.2.0 — симулятор подводного аппарата (ТНПА) СПбГМТУ
https://github.com/kholye/ROV-Sim

ЗАПУСК
  Распакуйте архив в любую папку и запустите ROV-Sim.exe. Установка не нужна.
  Требования: Windows 10/11 64 бит, видеокарта с OpenGL 3.3 (подходит встроенная),
  4 ГБ ОЗУ. Проверено на Ryzen 5 5500U со встроенной Radeon: 60 кадров/с при 1280×720.
  Windows SmartScreen может предупредить о неизвестном издателе (файл не подписан):
  «Подробнее» -> «Выполнить в любом случае».

УПРАВЛЕНИЕ (как пульт настоящего аппарата; полностью — F1 в игре)
  W S A D, стрелки / стик    ход и поворот (два движителя)
  E / Q                      обе цистерны: набрать / вытеснить воду (глубже / мельче)
  R / F, T / G               носовая / кормовая цистерна (дифферент)
  H                          удержание глубины (ПИД), PgUp / PgDn — цель на шаг мельче / глубже
  L                          лампа 0 / 50 / 100 %
  Tab                        стильный вид (по умолчанию выключен, есть в настройках)
  V, F2, F3, F4              окошко «со стороны», график глубины, силы, ослабление света
  Esc                        пауза, настройки, ПИД
  Крена, бокового и вертикального хода у аппарата нет — как у настоящего.
  Настройки: режим управления — научный, автопилот (держит курс, дифферент, глубину;
  E / Q — глубже / мельче) или автопилот + ускорение.

ГДЕ ДАННЫЕ
  Настройки, таблица результатов, отчёты осмотра судна и телеметрия (F9):
  %APPDATA%\Godot\app_userdata\ROV-Sim\
